# 项目介绍与架构原理

## 什么是 Draw.io Scientific Illustrator？

**Draw.io Scientific Illustrator** 是一个面向科研插图绘制的 Codex 插件。它能让 AI Agent 在**可见的桌面版 draw.io 画布**上实时绘制与修正科学图表。

与传统生成静态 `.drawio` XML 文件再交由用户打开的方式不同，本插件通过本机 MCP 协议（Model Context Protocol）直接连接至运行中的 draw.io 内部 Graph API。你可以实时观察到插图在画布中被逐笔构建的过程。

## 架构简图与核心组件

本项目包含以下四个主要组成部分：

1. **`drawio-live` MCP 服务**：
   - 启动或连接至开启了远程调试端口 (`--remote-debugging-port`) 的桌面版 draw.io 窗口；
   - 实时执行对当前活跃画板的图模型增删改查；
   - 截取当前渲染区域的视觉快照供 AI 进行视觉校验。

2. **`drawio-file-utils` MCP 服务**：
   - 校验保存的 `.drawio` XML 文件结构合法性；
   - 触发桌面版 draw.io 高清导出 PNG、SVG、PDF 或 JPG 格式。

3. **Codex Skill (Agent 技能包)**：
   - 引导 AI 模型进行参考图分解、图元识别、步进节奏控制、分区检查与交互式纠偏。

4. **Codex Marketplace 市场包**：
   - 将 MCP 服务、Skill 与元数据统一打包为一键安装的插件。

```
+-------------------------------------------------------------------+
|                           Codex Agent                             |
+-------------------------------------------------------------------+
       |                                             |
       v (MCP over Stdio)                            v (Skill 引导)
+-------------------------------+             +---------------------+
|  drawio-live & file-utils MCP |             | Scientific Skill    |
+-------------------------------+             +---------------------+
       |
       v (CDP WebSocket / Localhost)
+-------------------------------------------------------------------+
|               可见的 draw.io 桌面端窗口 (Graph API)                 |
+-------------------------------------------------------------------+
```

## 核心设计原则

- **零系统级自动化入侵**：不接管或模拟操作系统的键盘与鼠标。
- **拒绝盲写 XML**：绘制过程优先在图引擎中实时建立与交互，确认无误后才序列化落盘。
- **完整保持矢量可编辑性**：绘制生成的所有文本、几何形状、箭头和图例均保持为标准的 draw.io 矢量图元，方便研究人员后续手动修改。
- **纯本机安全保障**：所有通信均限制在 `127.0.0.1` 本机端口，无任何外部服务器数据上传。
